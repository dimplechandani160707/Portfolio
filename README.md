# Personal Portfolio

A personal developer portfolio showcasing my skills, learning journey, projects, and interests in software development.

## ✨ About

This portfolio is designed to present my journey as a **B.Tech Computer Science & Engineering student** and highlight the technologies I'm learning, the projects I'm building, and my interests in software development.

The goal was to keep the design **simple, modern, interactive, and recruiter-friendly** rather than making it overly complex.

## 🛠️ Built With

* **HTML5** — Structure and semantic markup
* **CSS3** — Styling, layouts, animations, and responsive design
* **JavaScript** — Interactions and dynamic functionality

## 📌 Features

* Responsive portfolio layout
* About Me section
* Skills and technologies
* Projects showcase
* Education section
* Contact section
* Interactive UI elements
* Mobile-friendly design

## 📂 Project Structure

Portfolio/

## 🚀 Getting Started

To run the portfolio locally:

```bash
git clone https://github.com/dimplechandani160707/Portfolio.git
cd Portfolio
```

Then open `index.html` in your browser.
